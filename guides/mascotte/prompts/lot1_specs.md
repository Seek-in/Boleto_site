# Lot 1 — 15 icônes prêtes à générer

Pour chaque icône : **Type** (MORPH FORT = corps devient l'objet · MORPH PARTIEL = corps ticket
gardé mais une partie se transforme), **Objet/props**, **Scène**, **Jambes** (expressives, façon
exemples Voyage/Mode), **Violet** (accent).
Base commune : plat, jaune dominant, chaussures violettes, jamais de bras, visage minimal.

**RÈGLE D'OR : Boleto est TOUJOURS transformé.** Il n'existe AUCUNE icône sans morph.
Le corps garde le gabarit ticket + encoches, mais **une partie se modifie toujours** pour le thème.
Un ticket neutre + accessoires posés à côté = INTERDIT.

Morph du corps par service (à appliquer À CHAQUE fois) : Café → **mousse/crème + volutes** sur le
haut, matière café · Restaurant → **cloche esquissée** qui coiffe le haut du corps · Coiffeur →
**mèche/houppette** stylée sur le haut · Pharmacie → **croix intégrée** au corps + forme de gélule
sur un bord · Optique → les bords du corps forment des **verres de lunette** · Fleuriste → le haut
du corps s'ouvre en **cache-pot** d'où sortent des fleurs · Sport → corps **bombé « musclé »** ·
Épicerie → corps en **panier/sac** (anses) · Bar → le corps **contient un cocktail** (verre) ·
Beauté → corps en **flacon** arrondi.

> Rappel workflow : Prompt A pour le perso (avec ticket de base en réf) → vectoriser →
> Prompt B pour la scène (avec le perso généré en réf).

---

### 1. Café — MORPH PARTIEL
- Props : une **tasse de café fumante jaune** avec un mini-visage (copain). Petite soucoupe.
- Scène : Boleto accoudé/appuyé sur sa tasse, moment détente.
- Jambes : assis, **jambes croisées** décontractées.
- Violet : chaussures + anse de la tasse violette.

### 2. Boulangerie — MORPH
- Objet : le corps devient un **croissant** (silhouette croissant, quelques stries).
- Scène : petit-déj, petite tasse jaune à côté.
- Jambes : décontracté, **une jambe pliée**.
- Violet : chaussures + petit pot de confiture violet.

### 3. Restaurant — MORPH PARTIEL (ticket gardé)
- Corps : ticket allongé, encoches gardées (léger habillage « nappe/serviette » possible).
- Props : une **cloche de service** soulevée à côté, **intérieur VIOLET** (l'effet que tu as adoré),
  une petite assiette + étincelles.
- Jambes : **une jambe levée**, dynamique.
- Violet : intérieur de la cloche + chaussures.

### 4. Pâtisserie — MORPH (format ticket conservé)
- Objet : le corps reste un **ticket allongé avec ses encoches**, mais **habillé en gâteau** :
  glaçage/crème qui coule sur le dessus, une couche de génoise + une couche de confiture visibles,
  une fraise posée dessus. **PAS un triangle**, pas juste de la crème sur un rectangle neutre :
  on lit « ticket-gâteau », encoches gardées.
- Scène : simple, gourmand.
- Jambes : petits pieds **joints**, sages.
- Violet : chaussures + une myrtille sur le gâteau.

### 5. Coiffeur — MORPH PARTIEL
- Props : un **sèche-cheveux** tenu avec un pied, une mèche stylisée qui vole.
- Scène : en plein brushing.
- Jambes : **une jambe tendue** qui tient le sèche-cheveux.
- Violet : sèche-cheveux violet + chaussures.

### 6. Pharmacie — MORPH PARTIEL
- Props : une petite **croix de pharmacie** sur lui + un flacon-copain jaune.
- Scène : rassurant, en forme.
- Jambes : droites, **sages**, légèrement écartées.
- Violet : la croix violette + chaussures.

### 7. Optique — MORPH PARTIEL
- Props : il **porte des lunettes** (sur le visage), un étui à côté.
- Scène : look malin.
- Jambes : **croisées** décontractées.
- Violet : monture des lunettes violette + chaussures.

### 8. Fleuriste — MORPH PARTIEL
- Props : un **bouquet** dans un pot, à côté ou tenu au pied.
- Scène : printanier.
- Jambes : **une jambe pliée**, léger.
- Violet : pot violet + chaussures (fleurs = petit accent coloré toléré).

### 9. Mode — MORPH
- Objet : le corps devient un **t-shirt sur un cintre** (comme ton exemple).
- Scène : épuré, style.
- Jambes : **écartées** façon exemple Mode.
- Violet : cintre violet + chaussures.

### 10. Chaussures — MORPH
- Objet : le corps devient une **basket / sneaker** (lacets).
- Scène : dynamique.
- Jambes : **en marche**, énergiques.
- Violet : détails de la basket (semelle/lacets) violets + chaussures.

### 11. Sport / Fitness — MORPH PARTIEL
- Props : un **haltère** soulevé avec les pieds.
- Scène : effort joyeux, petite goutte.
- Jambes : **en flexion**, écartées (position d'effort).
- Violet : haltère violet + chaussures.

### 12. Épicerie — MORPH PARTIEL
- Props : un **panier de courses** avec quelques provisions.
- Scène : il fait ses courses.
- Jambes : **en marche**.
- Violet : panier violet + chaussures.

### 13. Bar — MORPH léger / MORPH PARTIEL
- Props/objet : un **verre à cocktail** (tenu au pied) + tranche d'agrume, paille.
- Scène : ambiance cool, festif.
- Jambes : **croisées** décontractées, appuyé.
- Violet : cocktail/paille violet + chaussures.

### 14. Beauté / Institut — MORPH PARTIEL
- Props : un **miroir à main** + étincelles.
- Scène : glamour, il se mire.
- Jambes : **pose élégante**, une jambe pointée.
- Violet : cadre du miroir violet + chaussures.

### 15. Cadeaux — MORPH
- Objet : le corps devient un **paquet cadeau** (nœud sur le dessus).
- Scène : joyeux, festif, étincelles.
- Jambes : **sautillantes**, joyeuses.
- Violet : nœud/ruban violet + chaussures.
